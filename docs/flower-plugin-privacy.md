# Flower Plugin Privacy Policy

Effective date: August 12, 2026

## Scope

This policy applies to the Flower plugin for ChatGPT and Codex published by
Flower JVM. The plugin is a skills-only bundle containing documentation,
instructions, and static assets for working with Flower and Flower Action
Runtime. It does not operate a Flower JVM hosted service, user account system,
MCP server, or publisher-controlled telemetry endpoint.

## Data Handling

Flower JVM does not receive, collect, store, or sell prompts, source code,
workspace contents, generated output, or tool results through the plugin.

ChatGPT, Codex, and their host environment may process those data in order to
provide their services. That processing is governed by the policies and
settings of OpenAI and the organization or user operating the host
environment, not by this policy.

At the user's direction, a coding agent may run local build tools or contact
third-party services such as GitHub or Maven Central. Those tools and services
handle data under their own terms and privacy policies. The Flower plugin does
not receive their logs or responses independently of the active agent session.

## Support And Public Reports

Support and bug reports are accepted through the public
[Flower GitHub issue tracker](https://github.com/flowerjvm/flower/issues).
Information submitted there is processed by GitHub and is generally public.
Do not include passwords, API keys, confidential source code, personal data,
or other secrets in an issue.

## Changes And Contact

Material changes to this policy will be published at this URL with an updated
effective date. Questions about this policy may be submitted through the
[Flower GitHub issue tracker](https://github.com/flowerjvm/flower/issues).
