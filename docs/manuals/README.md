# Flower Module Manuals

In-depth guides to Flower's public APIs, available in English and Korean.
Each manual is a self-contained HTML document that can be read offline.

| Module | English | 한국어 | Status |
| --- | --- | --- | --- |
| `flower-core` | [Flower Core Manual](en/flower-core.html) | [Flower Core 사용 매뉴얼](ko/flower-core.html) | Stable API |
| `flower-eventloop` | [Flower EventLoop Manual](en/flower-eventloop.html) | [Flower EventLoop 사용 매뉴얼](ko/flower-eventloop.html) | MVP |

## Version scope

These manuals target Flower `0.1.3`. The `main` branch may contain later
snapshot changes, so consult the source and release documentation when working
against a different version.

The EventLoop module is marked **MVP** and may evolve more quickly than the Core
API.
